Chuyển HTML sản phẩm sang JSON

Dán HTML đã copy từ trang danh sách sản phẩm. Công cụ đọc tên, giá, đơn vị và ảnh; danh mục chọn từ danh sách bạn nhập. Không tải dữ liệu lên máy chủ.

SQL dùng categoryId đã chọn và giữ price: null. Chạy trực tiếp sẽ bỏ qua kiểm tra API và cache invalidation; cần có hierarchy migration trước, rồi xóa cache catalog trên backend. Hãy kiểm tra đúng database trước khi chạy.

Không đọc được giá thì xuất price: null. Sản phẩm cần dược sĩ tư vấn và không thể mua; backend cần hỗ trợ giá null.

Chuyển HTML danh mục sang JSON

Dán HTML lưới danh mục. Công cụ lấy tên từ tiêu đề h2 (hoặc label ở mẫu cũ) và URL ảnh từ img[src]; tự bỏ mục “Xem tất cả” không có ảnh.
